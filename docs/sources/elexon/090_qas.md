# QAS, balancing services volume (ABSVD)

How it is loaded: [091_qas_ingestion.md](091_qas_ingestion.md).

## In plain terms

**Energy the operator asked for outside the balancing mechanism.** Besides
bid-offer acceptances, the system operator buys services under separate
contracts: frequency response, intertrips, the Maximum Generation Service and
the Demand Flexibility Service. A unit delivering one of them moves away from
its notified level without any acceptance.

NESO sends Elexon the energy each unit delivered for those services in each
settlement period: the applicable balancing services volume (ABSVD), published
on Insights as QAS. Settlement adds it to the unit's expected volume beside the
acceptances (BSC Section T 4.3.2).

Without it, a battery providing frequency response looks like a unit that
missed its notification.

## Endpoint

```
GET https://data.elexon.co.uk/bmrs/api/v1/balancing/nonbm/volumes
```

| Parameter | Required |
|---|---|
| `from`, `to` | yes. Start times by default; settlement dates when a period parameter is present |
| `settlementPeriodFrom`, `settlementPeriodTo` | no. 1 to 50 |
| `bmUnit` | no, repeatable |
| `format` | no. `json` adds the `metadata` envelope |

## Response fields

`{"metadata": {"datasets": ["QAS"]}, "data": [...]}`, one row per unit and
settlement period.

| Field | Type | Notes |
|---|---|---|
| `settlementDate` | `str` | Local time date |
| `settlementPeriod` | `int` | 1 to 46/48/50 |
| `bmUnitApplicableBalancingServicesVolume` | number | MWh, positive or negative, three decimals |
| `nationalGridBmUnit` | `str` | Marked nullable in the API schema |
| `bmUnit` | `str` | Marked nullable in the API schema |
| `time` | `str` | Computed by the API from the date and period |

## Traps

- **Ask by settlement date.** Without a period parameter, `from` and `to` are
  start times, and a summer date loses periods 1 and 2 (they start the
  evening before, in UTC).
- **Zero rows exist.** Volumes are "normally only provided where there is a
  non-zero volume", yet 112 of 5,571 rows on 1 October 2026 were exactly 0. A
  unit-period with no row has no ABSVD.
- **Secondary units.** Rows include secondary BM units, whose `bmUnit`
  (`2__…`, `V__…`) differs from `nationalGridBmUnit` beyond the prefix. Each
  National Grid identifier has one `bmUnit`.
- **No version.** NESO may resubmit a value before Final Reconciliation (BSC
  Section Q 6.4.3). The response carries no publication time or version, so a
  change is seen only by capturing the date again.

## Size

About 4,400 to 5,600 rows a day (29 March and 1 October 2026), about 150 units,
90 or more rows in every period. History goes back to at least 2017.
